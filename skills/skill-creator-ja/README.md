# skill-creator-ja

## 概要
`skill-creator-ja` は、Codex 向けスキルの新規作成・改修を効率的に行うためのスキルです。  
要件の曖昧さを先に解消し、日本語の仕様ドキュメントを必ず残す運用を標準化します。

## このスキルが対応する内容
- 新しいスキルの設計とひな形作成
- 既存スキルの改善（`SKILL.md`、`agents/openai.yaml`、関連リソース）
- スキル品質の最低限バリデーション

## 必須動作
1. 不明点や曖昧な要件がある場合は、実装前にユーザへ質問する  
2. 作成・更新するスキルに対して、`README.md` を日本語で作成する  
3. 作業完了後に、次の確認を必ず行う  
   `作成したスキルを ~/.agents/skills/ に移動して問題ないですか？`

## 推奨ワークフロー
1. 要件を確認し、ブロッカーとなる不明点を整理する
2. 必要に応じて 1-3 個の短い質問で不明点を解消する
3. 新規作成時は `init_skill.py` で雛形を作る
4. `SKILL.md` とリソースを実装する
5. `README.md` を日本語で整備する
6. `quick_validate.py` で検証する
7. 完了報告と移動可否の確認を行う

## 作成される主なファイル
- `SKILL.md`: エージェント向け実行手順とトリガー定義
- `README.md`: 人間向け仕様（日本語）
- `agents/openai.yaml`: UI 用メタデータ
- `scripts/` `references/` `assets/`: 必要時のみ

## 注意点
- 質問は多くしすぎず、実装の障害になる項目を優先する
- `SKILL.md` と `README.md` の記述が矛盾しないようにする
- 不要な補助ドキュメントを増やしすぎない
