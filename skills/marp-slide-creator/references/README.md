# marp-slide-creator

Marpを使ってMarkdownでプレゼンテーションスライドを作成・レビューするためのスキルです。

## 概要

Marp（Markdown Presentation Ecosystem）を用いたスライド作成をエージェントがサポートします。Marp CLIのインストール確認から、スライドの新規作成・レビューまでを一貫してガイドします。すべてのスライドは `~/slide/` に保存されます。

---

## トリガー条件

以下のような発言・依頼でスキルが呼び出されます：

- 「スライドを作成して」
- 「プレゼン資料を作りたい」
- 「Marpでスライドを作って」
- 「作ったスライドをレビューして」
- "create a slide"
- "make slides"
- "presentation"

---

## 実行フロー

### 共通：環境チェック

1. `marp --version` でMarp CLIの存在確認
2. 未インストールの場合 → `npm install -g @marp-team/marp-cli` を実行
3. Node.js/npmが存在しない場合 → ユーザーにインストールを案内

### 作成モード

1. テーマ・スライド数・対象読者などの要件をユーザーから収集
2. ファイル名をkebab-caseで決定（例：`intro-to-kubernetes.md`）
3. `~/slide/` ディレクトリを作成（存在しない場合）
4. `marp: true` を含むフロントマター付きのMarkdownファイルを生成・保存
5. 最初のスライドをプレビューとして表示し、保存先パスを通知

### レビューモード

1. `~/slide/` 内のファイルをリストアップ（ファイル名が未指定の場合）
2. 対象ファイルを読み込み、以下の観点でチェック：
   - 構造（フロントマター・スライド区切り・見出し）
   - コンテンツ（論理的な流れ・一貫性・誤字脱字）
   - Marp構文（ディレクティブ・画像構文）
   - 可読性（テキスト量・見出しの適切さ）
3. 良い点・改善提案・Marp構文の問題を構造化して報告
4. 修正の自動適用を提案

---

## 必須ルール

- スライドファイルは必ず `~/slide/` に保存する
- ファイル拡張子は `.md`
- 全ファイルのフロントマターに `marp: true` を含める
- 操作前に必ずMarp CLIのインストール確認を行う
- レビューフィードバックは具体的・実行可能な内容にする

## ファイル構成

```
~/.claude/skills/marp-slide-creator/
├── SKILL.md                        # スキル本体（エージェント向け指示）
└── references/
    ├── README.md                   # このファイル
    ├── marp-syntax.md              # Marp構文完全リファレンス
    ├── marp-themes.md              # テーマ詳細・ディレクティブ設定
    ├── marp-images.md              # 画像配置パターン集
    └── troubleshooting.md          # よくある問題と解決策
```

---

## 参照リファレンス

| ファイル | 内容 |
|----------|------|
| `marp-syntax.md` | フロントマター・スライド区切り・見出し・リスト・コードブロック・テーブル・数式など |
| `marp-themes.md` | `default` / `gaia` / `uncover` の特徴、グローバル/ローカル カラー設定、カスタムテーマCSS |
| `marp-images.md` | `![bg]` 構文・スプリットレイアウト・フィルター・複数背景画像・よくあるレイアウトパターン |
| `troubleshooting.md` | CLI未認識・テーマ不適用・画像非表示・ディレクティブ無効・VS Codeプレビューなど |

---

## 制約・注意事項

- エクスポート（PDF/HTML/PPTX）はこのスキルのスコープ外
- カスタムテーマCSSの作成はサポートするが、外部CSSライブラリの読み込みは対象外
- 画像パスはスライドファイルからの相対パスで解決される（`~/slide/images/` 推奨）
- Marp CLI バージョンによって一部機能が異なる場合がある
