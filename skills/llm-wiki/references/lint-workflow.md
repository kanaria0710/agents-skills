# Lint ワークフロー

wikiのヘルスチェック手順。

## チェック項目

### 1. 孤立ページ
他のページやインデックスからリンクされていないwikiページ。

### 2. 壊れたリンク
`[[wiki-links]]` のリンク先ページが存在しない。

### 3. 欠落クロスリファレンス
ページ内でエンティティ/コンセプト名が言及されているが `[[wiki-links]]` でリンクされていない。

### 4. インデックス不整合
`wiki/` 内に存在するが `wiki/index.md` に登録されていないページ。

### 5. フロントマター不備
必須フィールド（title, type, sources, created, updated）が欠けているページ。

### 6. 空のsourcesリスト
index.md, log.md以外でsourcesリストが空のページ。

### 7. 古い情報
`updated` が90日以上前のページ（閾値は調整可能）。

### 8. 矛盾の検出
異なるページで同じ事実について矛盾する記述がある場合。同じトピックやエンティティに関するページを比較して検出する。

### 9. 新規ページの提案
3つ以上のソース要約で言及されているが、独自のページを持たないエンティティやコンセプト。

## チェック手順

1. `wiki/index.md` を読み込み、登録済みページの一覧を作成
2. `wiki/` 内の全 `.md` ファイルを Glob で取得
3. 各ファイルについて:
   - フロントマターを解析（title, type, sources, created, updated）
   - 本文内の `[[...]]` リンクを抽出
4. クロスチェック:
   - すべてのリンク先が実在するか確認
   - すべてのファイルがインデックスに登録されているか確認
   - すべてのファイルが他のページからリンクされているか確認
5. Grep でエンティティ/コンセプト名を検索し、リンクされていない言及を検出
6. 矛盾の検出: 同一トピックのページ群を読み比べる

## レポート形式

```markdown
# Wiki Lint レポート — YYYY-MM-DD

## 重大な問題
- [ ] 壊れたリンク: [[nonexistent-page]] in source-article.md
- [ ] インデックス未登録: concept-emergent-behavior.md

## 警告
- [ ] 孤立ページ: entity-old-tool.md（リンク元なし）
- [ ] 古いページ: source-old-article.md（最終更新: 120日前）

## 提案
- [ ] 「transformer」が4つのソースで言及されているがコンセプトページなし
- [ ] 比較ページの提案: entity-tool-a vs entity-tool-b

## 統計
- 総ページ数: N
- Sources: N, Entities: N, Concepts: N, Comparisons: N, Synthesis: N
- クロスリファレンス密度: Nリンク / Nページ = 平均N
```

## 自動修正 vs 提案

### 自動修正可能（ユーザーに確認して実行）
- インデックスへの未登録ページの追加
- フロントマターの `updated` フィールド補完（ファイル更新日を使用）
- リンクされていないエンティティ/コンセプト名への `[[wiki-links]]` 追加

### 提案のみ（ユーザーの判断が必要）
- 新規エンティティ/コンセプトページの作成
- 矛盾の解消
- 孤立ページの削除
- 比較/統合ページの作成

## ログ更新

チェック完了後、`wiki/log.md` に追記:

```markdown
## [YYYY-MM-DD] lint | ヘルスチェック
- 重大な問題: N件
- 警告: N件
- 提案: N件
- 自動修正: N件実施
```
